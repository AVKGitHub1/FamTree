# Marathi Family Relationship Reference

A broad reference to Marathi relationship names and natural phrases, including extended relationships such as **आईची मावशी**.

Read every row as **“A is B’s…”**, with B as the reference person. Male and female forms are identified in the tables. Slashes within a single name indicate alternative terms unless otherwise stated.

The extended descriptions combine familiar Marathi kinship terms. They are natural descriptions of specific family connections, rather than claims that every relationship has a separate dictionary name. Family and regional usage can vary.

## 1. Parents, siblings, children, and spouses

| Relationship to B | Marathi name |
|---|---|
| Mother | आई |
| Father | वडील / बाबा |
| Parents | आई-वडील |
| Brother | भाऊ |
| Sister | बहीण |
| Elder brother | मोठा भाऊ / दादा |
| Younger brother | धाकटा भाऊ |
| Elder sister | मोठी बहीण / ताई |
| Younger sister | धाकटी बहीण |
| Sibling, without specifying gender | भावंड |
| Son | मुलगा |
| Daughter | मुलगी |

| Husband | नवरा / पती |
| Wife | बायको / पत्नी |
| Spouse, without specifying gender | जोडीदार |

Source for the basic vocabulary: [Family words in Marathi — Omniglot](https://www.omniglot.com/language/kinship/marathi.htm).

## Using the descriptions

- Keep the reference person fixed: every entry describes **A in relation to B**.
- Use **चुलत, आत्ये, मामे, or मावस** according to the actual connecting branch, rather than translating every cousin as चुलत.
- Use **आईची मावशी**, for example, when that familiar combination expresses the relationship naturally.
- Add **आईकडचे / वडिलांकडचे** when identifying the side of a grandparent matters.
- “Once removed” or “twice removed” does not identify a single Marathi name by itself. The branch and the direction of the generation difference are also needed.
- These tables use **भाऊ / बहीण** without introducing a full-sibling versus half-sibling distinction, consistent with the original calculator.
- Natural descriptions can continue through further generations; this is a broad reference rather than an exhaustive list of every possible family path.
